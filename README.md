# Nuca

Amiga de voz para niños (6 años): deberes de sumas y restas, cuentos clásicos en su versión tradicional, música infantil y comentarios sobre sus dibujos con la cámara.

Abre en Chrome de Android: https://frodocambra-ui.github.io/nuca/ y usa «Añadir a pantalla de inicio».

Prototipo web (PWA). Sin claves secretas: la charla libre usa el servicio gratuito de Pollinations; los cuentos y las cuentas funcionan sin IA.
